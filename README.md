# Reco-Spark

This repository contains a distributed movie recommendation engine built using Apache Spark (PySpark), FastAPI, and React.

## Folder Structure
* `data/`: The MovieLens dataset will be placed here (ignored by git).
* `ml_pipeline/`: Data processing and ALS model training with PySpark.
* `backend/`: FastAPI server for online serving.
* `frontend/`: Web user interface.
